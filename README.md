# Real Estate Agency Portal

## Project Description
This project is a web-based Real Estate Agency Portal developed using PHP and MySQL.

The platform allows:
- Agents to manage property listings
- Buyers and renters to browse properties
- Users to submit inquiries and save favorites

## Technologies Used
- PHP
- MySQL
- HTML/CSS
- PDO
- phpMyAdmin
- XAMPP

## Features
- User registration and login
- Role-based access control
- Property listings
- Favorites system
- Inquiry system
- Stored procedures
- Views and triggers

## Setup Instructions

1. Copy the uploaded files into htdocs
2. Start Apache and MySQL in XAMPP
3. Import 'real_estate_portal_final.sql' into phpMyAdmin
4. Open browser:
   http://localhost/real_estate_portal/
